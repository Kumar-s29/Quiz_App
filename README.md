# Quiz Application

This is a React-based quiz application that displays questions, tracks the user's progress, and shows a timer and streak indicator.

## Project Overview

The Quiz Application consists of the following main features:

- Displays a question with multiple options.
- Tracks the user's progress through the quiz.
- Shows a timer for each question.
- Indicates the user's current streak of correct answers.

## Setup Instructions

### Prerequisites

Before you begin, ensure you have the following installed on your machine:

- Node.js (v14 or later)
- npm (v6 or later) or yarn (v1.22 or later)

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/your-username/quiz-app.git
   cd quiz-app
   ```

2. Install the dependencies:

   ```sh
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```sh
   npm start
   # or
   yarn start
   ```

4. Open your browser and navigate to `http://localhost:3000` to see the application running.
